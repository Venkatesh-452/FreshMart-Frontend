# FreshMart Frontend

React + Vite frontend for the FreshMart vegetable shopping application.

## Run locally

```bash
npm install
npm run dev
```

## Features
- Home and product catalog
- Product search
- Shopping cart
- Checkout and order success flow
- Login UI
- Admin dashboard
- Product, category, user, order and payment management screens

The project structure and functionality were reconstructed from the uploaded FreshMart Code Document.
